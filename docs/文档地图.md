# 文档地图

> 不知道从哪看起时，先看这一页。信息只写一份，其它地方给链接。

## 该看哪份

| 你想知道 | 看这里 |
|---|---|
| 当前版本、最近改了什么 | `CHANGELOG.md` 顶部；`extension/manifest.json` |
| "这东西到底是什么、边界在哪" | `参考文档.md`（契约与验收依据）；不想读全文就先看 §1 与附录 C |
| "为什么当初这么定" | `docs/决策记录.md` 搜 `D-xxxx`；只想快速了解历史就看 `docs/history/早期阶段摘要.md` |
| 普通用户怎么用 | `docs/使用指南.md`（由 `extension/data/guide/zh-cn.json` 生成，别手改） |
| 别的扩展怎么接 | `docs/UI扩展接口.md` |
| 新接手的人/agent 从哪开始 | 接手 ILB 本身：`docs/交接-给下个智能体.md`；只做 UI 扩展：`docs/交接-UI扩展.md`（**不要**为了做 UI 去读 ILB 内部代码） |
| 这一阶段在做什么 | `docs/开发规划-现阶段.md`；更早的 UI 扩展设想在 `docs/下一阶段-UI扩展方案.md` |
| 旧版本文档原文 | `docs/历史/`（v1.0 结构快照）、`docs/history/`（阶段摘要） |

## 目录约定

```
extension/          真正会被 SillyTavern 加载的扩展（manifest 只声明 index.js）
  core/             纯计算：模型、判定、流程、变量、字段、调用解析
  runtime/          装配：管线、对外接口 api.js、注册表
  adapters/         宿主边界：存储、原生世界书、注入
  ui/               界面：面板、各页、编辑器、双壳
  data/             文案：guide（使用说明）、help（页内帮助）
  tests/            单测、链接检查、假 DOM 冒烟、演示脚本、探针页
memory/             已移出的叙事模块（留档，不加载）
docs/               规格、决策、历史、规划
  history/          压缩过的早期阶段摘要
  agents/           临时产物（不入库）
github/             发布镜像（同源代码 + docs），从这里推 GitHub
backup/             版本快照（整包），回退用
```

## 维护纪律

- `参考文档.md` 的编号条款只增不改；废弃就标 ⛔ 并写替代编号。
- `CHANGELOG.md` 只追加，最新在最上面。
- 改了做法就要在 `docs/决策记录.md` 写一条 `D-xxxx`（含"否决了什么、代价是什么"）。
- 文档里的数字（测试数、模块数、步骤数）改了代码就要同步，别让它们过期。
