# 早期阶段摘要（v0.1 – v0.10）

> 这份文件是**压缩过的历史**，给"想快速了解来龙去脉"的人和 agent 用。
> 原始细节仍在 `docs/决策记录.md`（D-0001 起，只追加）与 `CHANGELOG.md` 里，**不要删它们**；日常不用通读，查具体决定时再搜编号。
>
> 归档时间：2026-10-25。当前版本见 `extension/manifest.json`。

## 一句话

ILB 最初是"多本世界书并存 + 能查为什么没触发"的加载器；v0.6–v0.9 长出了"确定性状态账本"与"独立逻辑"；v0.8 把重账本移出、只留变量与流程；v0.10 让逻辑能脱离条目、能掷骰子、能每轮常驻。

## 早期踩过的坑（还在反复踩的）

1. **PowerShell 改中文文件**：`Get-Content | Set-Content` 会把无 BOM UTF-8 当 GBK 写坏。只用 `edit`/`write` 工具或 node `fs`（`utf8`）。
2. **`git -C <dir> commit -F 相对路径`**：相对路径按 `<dir>` 解析，会找不到消息文件；用绝对路径。
3. **`git push` 的 `schannel: failed to receive handshake`**：网络/代理侧 TLS 抖动，过几分钟重试即可，不是代码问题。
4. **`node --test tests/`**：目录形式在部分 Node 版本上会失败；用 `node --test tests/*.test.mjs`。
5. **提交消息的 BOM**：`Set-Content -Encoding utf8`（PS 5.1）会加 BOM；用 node `fs.writeFileSync(...,'utf8')` 写提交消息。
6. **`robocopy` 不覆盖时间戳更旧的大文件**：`参考文档.md` / `CHANGELOG.md` 要用 `Copy-Item -Force`，复制完 `Get-FileHash` 比对。
