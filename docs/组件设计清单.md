# 组件设计清单（避免二次返工）

> 这份文档不是开发记录，也不记“某版本改了什么”。它只回答一个问题：
> **下次再做「可搜索下拉 / 搜索筛选 / 信息卡片 / 顶部工具条」时，一次就要想到哪些事？**
>
> 来源是 ILB 里真实返工过的几次：手机底栏随内容跑、`hidden` 被 `display:flex` 盖掉、
> 下拉模型与控件形状不一致导致切不动页、折叠条点第二次收不起来、卡片“紧凑”只差几像素。
> 每一条都写成可勾选的检查项；写代码前过一遍，能省掉一轮“看起来能用、真机才发现不对”。

## 0. 通用原则

- [ ] **状态只有一份**：界面状态（展开了哪组、选中了谁、搜索词）放在一个地方，DOM 只反映它；不要两处各改一半。
- [ ] **状态要能持久**：用户切换过的（紧凑/舒适、搜索范围、折叠与否、排序）写进 `uiState`，刷新/重开还在。
- [ ] **默认值对老数据友好**：新键缺省时按“不改变旧行为”取值；读不到就补默认，不要报错、不要清空。
- [ ] **能看不见的失败等于失败**：算不出来、找不到、被拦下，都要有一句人能看懂的话；不要静默 `return`。
- [ ] **真浏览器才是裁判**：假 DOM 不跑 CSS、不实现 `hidden`/`disabled` 原生语义、不算布局；凡是“显示/隐藏/尺寸/遮挡”，必须有一条真浏览器探针或真机手测。

## 1. 可搜索选择器（书籍 / 分组 / 逻辑组 / 任意长列表）

**什么时候必须用**：候选项可能超过 ~10 条、名字可能很长、手机上要单手选。实体列表（书、组、角色）一律不要用原生 `<select>`。

- [ ] 触发器只显示**当前值**（没有就显示占位），带一个 `▾`；不要把所有选项平铺在页面里。
- [ ] 面板里有**搜索框**，输入即过滤；多个关键词按 AND（和列表搜索一致）。
- [ ] 搜索匹配**标签 + 副说明**（例如书名 + “N 条规则 · M 条逻辑”），而不是只匹配 value。
- [ ] 当前项有**选中标记**，并用 `aria-haspopup="dialog"`。
- [ ] 没有结果时给**空态文案**（“没有匹配的… ”），不要留白。
- [ ] 列表可滚动（`max-height` + `overflow:auto`），手机上不要超过半屏。
- [ ] 回车选第一条、点条目即选并关闭；关闭走统一的 `closeOverlay()`（手机上是二级页，不是浮层）。
- [ ] 触控目标 ≥ 40–44px；长名字省略号（`text-overflow:ellipsis`），不要把布局撑破。
- [ ] 选择会改变全局上下文（如当前书籍）时，先走**未保存守卫**，再改状态、再重画。
- [ ] 值变化后**同一帧内**重画，别留下“按钮显示新书、列表还是旧书”的中间态。

**反例（ILB 真踩过）**：模型给的是 `{ id, label }`，控件要 `{ value, label }`，直接传下去后 `<option>` 的 value 退化成文字，`setTab('逻辑')` 静默无效。**模型形状与控件形状在表现层翻译，翻译处写一句注释，并用冒烟断言 option 值必须是页面 id。**

## 2. 搜索与筛选

- [ ] **范围要明说**：只搜标题，还是含正文/触发词/内部条目？用一个可见的「范围」选择器，不要靠猜。
- [ ] 范围也要**持久化**（同一页下次打开还是上次的选择）。
- [ ] 关键词按 AND 拆分（空格/全角空格/逗号）；全角空格当分隔符。
- [ ] 组合条件（关键词 + 分组 + 模式）是 AND；清空筛选要一次性清干净并重画。
- [ ] 有筛选时显示**命中/总数**（“3 / 12 条”），没有筛选时显示总数。
- [ ] 空结果给一句“没有匹配…换个关键词”，不要显示空白列表。
- [ ] 搜索只影响“看得到什么”，**不改数据、不改顺序、不影响判定**；批量操作只作用于当前结果。
- [ ] 搜索框在手机上放进顶部“筛选”组或常显，不要藏在二级页里。
- [ ] 搜索范围、排序、选择模式之间互不覆盖；切换页面回来保持。

**反例**：书架搜索原先默认搜内部条目标题，用户以为“搜书名”，搜出一堆不相关的书。现在默认「只搜书名/来源」，要搜内部条目必须显式切范围。

## 3. 信息卡片（三级结构）

- [ ] **一级只放摘要**：选择框、标题、启用状态、2–5 个关键标签、`⋯`、进入详情的入口。
- [ ] **二级展开**才放管理项（策略、开关、关联、来源/时间等），默认不展开；展开状态在会话内保留。
- [ ] **三级 `⋯`** 放低频/危险操作（导出、复制、删除、完整元数据）；删除必须二次确认。
- [ ] 点击分区明确：点标题=进入、点选择框=只改选择、点 `⋯`=只开菜单、点展开=只展开；**互不触发**。
- [ ] `⋯` 菜单同一时间只开一个；点页面别处收起；菜单不要被后面的卡片盖住（`z-index` / 定位检查）。
- [ ] **紧凑/舒适必须真的不一样**：不只是 padding，而是信息量不同（例如紧凑隐藏“酒馆关联”行/词数，舒适显示）；差异要能截图看出来。
- [ ] 紧凑是默认；切换写 `uiState`，刷新还在。
- [ ] 展开后的管理区也要紧凑：两列网格、字段高 28–30px、说明一行以内，不要又变回一整屏。
- [ ] 元数据（来源、指纹、导入时间）只放展开区，不占一级视觉。
- [ ] 触控目标 ≥ 44px（图标按钮可用 34–36px 视觉 + 外扩热区）。
- [ ] 窄屏（320–430px）不横向溢出；超长标题/组名换行或省略，二者选一并写清楚。

**反例**：v0.22 的“紧凑/舒适”只改了 padding，用户反馈“几乎没变化”。v0.24 改成信息层差异（显示/隐藏整行）才有意义。

## 4. 顶部工具条 / 折叠菜单

- [ ] 工具条**属于标题栏**（在 header 里），不要用 `sticky` 浮在滚动内容上——否则会遮住页面按钮，内容短时还会“浮”在半空。
- [ ] 背景条高度 ≈ 按钮高度 **+1~2px**，不要留一大圈空白；按钮本身不要被全局按钮样式撑大（注意 `.ilb-m button` 这类宽选择器的优先级）。
- [ ] 默认**全部收起**；每点一个展开对应一组，其余自动收起；**再点同一个要能收起**。
- [ ] 展开/收起只走**一个函数**（状态 + 行 + 高亮 + `aria-expanded` + 箭头一起改）；不要再挂一个“装饰性”的委托监听。
- [ ] 点工具条以外收起（文档级监听只绑一次，别每次重画都绑）。
- [ ] 标题栏最右侧提供**整条折叠按钮**（收起后只剩标题行），状态持久化。
- [ ] 工具条不参与滚动；打开组时不改变底栏位置；键盘弹出时不重排版面（ILB 的选择：允许被遮挡，不跟着 `visualViewport` 跳）。
- [ ] 每组内容按当前页生成（新建/排序/筛选/书籍），不要出现“这一页没有的东西”。

**反例**：折叠条内联 `onclick` 先藏行，容器委托监听又按点到的按钮把行显示回来 → 状态与画面不一致，第二次点击像“没反应”。修法是只保留一个 `setOpen()`。

## 5. 显示/隐藏

- [ ] 用 `hidden` 时，确认没有被 `.xxx { display:flex/grid }` 盖掉；`.ilb-root/.ilb-window/.ilb-overlay/.ilb-m` 里保留 `[hidden]{display:none!important}` 兜底，并有一条 CSS 单测守着。
- [ ] 假 DOM 不联动 `hidden` 属性与 property：需要同时写 `node.hidden = true` 和 `setAttribute('hidden','')`（或统一走工具函数）。
- [ ] 条件渲染 vs 隐藏：需要保留输入状态/焦点的用隐藏，不需要的可以直接不渲染；二者不要混着用在同一块。
- [ ] 真浏览器探针要断言 `getComputedStyle(...).display` 或 `getBoundingClientRect()`，不能只看元素在不在。

## 6. 状态与数据

- [ ] 界面状态键集中在一处（ILB：`uiState`），命名带页面前缀（`shelfMode`、`searchScope.rules`、`topFolded`）。
- [ ] 写 `uiState` 失败只影响本次会话，不阻断操作（`try/catch` + 注释）。
- [ ] 破坏性操作（删组、删书）先二次确认；删除组要说清“组里还有 N 条逻辑会一起删”。
- [ ] 排序/搜索/折叠不改条目数组本身，只改“看”的顺序与可见性。
- [ ] 新功能默认关闭或行为不变；老数据缺字段补默认，不做隐式迁移。

## 7. 交付前自检（每次都跑）

- [ ] 单元测试覆盖纯模型（搜索范围、排序层、运行时筛选）。
- [ ] 假 DOM 冒烟覆盖交互路径（展开/收起、切页、开关、菜单）。
- [ ] 真浏览器探针覆盖布局与可见性（尺寸、遮挡、`display`、切换后落盘）——至少桌面 + 手机视口各一条。
- [ ] 真机手测清单单独列（软键盘、返回键、触控热区、深色主题、超长文本、320–430px）。
- [ ] 文档同步：CHANGELOG、决策记录（D-编号）、参考文档状态行、开发规划进展、交接文档数字。
- [ ] 一键发布并等 CI 绿；发布前把 `extension/` 同步给本机酒馆，探针验的是新版。

## 8. 一页速查（贴在显示器边上）

| 要做的事 | 必须一起想到 |
|---|---|
| 加一个下拉 | 搜索、空态、当前值勾、滚动、44px、状态翻译、持久化 |
| 加一个搜索框 | 范围明示、AND 拆分、计数、空态、清空、不动数据 |
| 加一张卡片 | 三级信息、`⋯` 分区、紧凑/舒适差异、展开区密度、删除确认 |
| 加一条工具栏 | 在 header 里、高度≈按钮+2、默认收起、互斥、整条折叠、点外收起 |
| 加一个“隐藏” | `[hidden]` 兜底、property+attribute、真浏览器断言 |
| 加一个状态 | `uiState` 键名、默认值、老数据、刷新后还在 |
